# SAMSA SWAP - Match-3 Game 🥟

Игра "3 в ряд" с восточной кухней на Phaser 3 + TypeScript + Vite

🎮 **[Играть онлайн](https://babang1da.github.io/cheburek-game/)**

## Особенности

- ✅ Сетка 6×9 с крупными элементами
- ✅ Управление свайпами (drag & drop)
- ✅ Комбо-система с множителем
- ✅ Сохранение рекорда
- ✅ 6 видов восточной еды

## Разработка

```bash
npm install
npm run dev
```

## Деплой на GitHub Pages

Игра автоматически деплоится на GitHub Pages при пуше в `main` ветку.

Или вручную:
```bash
npm run build
# Загрузить содержимое папки dist/ на GitHub Pages
```

## Технологии

- Phaser 3 - игровой движок
- TypeScript - типизация
- Vite - сборщик
